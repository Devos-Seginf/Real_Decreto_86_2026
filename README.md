# Real_Decreto_86_2026
Certificado profesional de Habilitación para la docencia en grados A, B y C


**Resumen de los puntos más importantes del Real Decreto 86/2026** (Certificado profesional de Habilitación para la docencia en grados A, B y C)

Este Real Decreto crea el **nuevo certificado profesional** que habilita para impartir docencia en los grados A, B y C del Sistema de Formación Profesional. Sustituye al antiguo certificado de profesionalidad **SSCE0110 “Docencia de la formación profesional para el empleo”**.

### Datos de identificación del certificado (Art. 2)

|Elemento|Dato|
|---|---|
|**Denominación**|Habilitación para la docencia en grados A, B y C del Sistema de Formación Profesional|
|**Código**|SSC_C_017_5B|
|**Nivel**|3|
|**Duración**|**510 horas**|
|**Familia profesional**|Servicios Socioculturales y a la Comunidad|
|**MECU**|5B|
|**CINE**|P-4.5.3|

### Competencia general (Art. 4)

Programar, impartir, tutorizar y evaluar acciones formativas de los grados A, B y C (en modalidad presencial, semipresencial y virtual), elaborando materiales didácticos, orientando sobre itinerarios y salidas profesionales, impulsando la calidad docente, la competencia digital y aplicando la prevención de riesgos laborales.

### Módulos profesionales (Art. 8) — importante

1. **1705** – Programación didáctica de los grados A, B y C (90 h)
2. **1706** – Gestión de materiales, medios y recursos didácticos (90 h)
3. **1707** – Orientación profesional en los grados A, B y C (60 h)
4. **1783** – Evaluación del proceso de enseñanza-aprendizaje (60 h)
5. **1784** – Procesos para impartir acciones formativas (90 h)
6. **1785** – Acción tutorial de los grados A, B y C (60 h)
7. **1786** – Competencia digital para la práctica docente
8. **1782** – Prevención de riesgos laborales

### Estándares de competencia incluidos (Art. 6)

- ECP1442_3: Programar acciones formativas
- ECP1443_3: Gestionar materiales y recursos didácticos
- ECP1446_3: Facilitar información y orientación laboral
- ECP1445_3: Evaluar el proceso de enseñanza-aprendizaje
- ECP1444_3: Impartir acciones formativas
- ECP2689_3: Tutorizar acciones formativas

### Requisitos para impartir este certificado (Art. 11)

Para poder dar clase en este certificado se necesita:

- Título universitario (o equivalente) + este mismo certificado de habilitación, **o**
- Pertenecer a las especialidades docentes del sistema educativo (anexo V), **o**
- Experiencia profesional de al menos 4 años + este certificado de habilitación.

Las administraciones pueden **eximir** del certificado de habilitación durante la primera acción formativa.

### Acceso al certificado (Art. 12)

Como es de **nivel 3**:

- Título de Técnico o Técnico Superior, Bachiller, certificado profesional de nivel 3, certificado de competencia incluido, o certificado profesional de nivel 2 de la misma familia.
- Si no se cumplen, se puede acceder por prueba de acceso (Art. 76 del RD 659/2023).

### Equivalencia con el certificado antiguo (DA 4.ª) 

El antiguo certificado **SSCE0110 “Docencia de la formación profesional para el empleo”** se considera **equivalente a todos los efectos** a este nuevo certificado (SSC_C_017_5B).

- Los centros que estaban autorizados para el SSCE0110 quedan automáticamente autorizados para el nuevo.
- Quienes tengan el SSCE0110 mantienen la competencia para impartir docencia en grados A, B y C.

### Otros puntos importantes

- Es un certificado **dual** (incluye formación en empresa).
- Para iniciar la estancia en empresa hay que haber superado el módulo de **Prevención de Riesgos Laborales** (nivel básico).
- No regula una profesión regulada (DA 1.ª).
- Se puede ofertar en modalidad presencial, semipresencial y virtual.
- Entrada en vigor: a los 20 días de su publicación en el BOE (febrero 2026).
